# PlanSpace Claim Evidence Ledger

## Main-paper argument map

**Thesis.** Planning benchmarks can conflate reference reproduction,
goal-reaching behavior, and interface compliance. PlanSpace measures these
axes separately and shows that the separation changes the interpretation of
model scores.
